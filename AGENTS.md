# Communication Rules

- Запрещено использовать шаблонные вводные конструкции и клише:
  - «короткий ответ»
  - «честный ответ»
  - «если не врать»
  - «без воды»
  - «честно говоря»
  - «коротко говоря»
  - и аналогичные фразы.
- Ответ должен начинаться сразу по существу вопроса — прямо, конкретно и без искусственных вводных речевых штампов.
